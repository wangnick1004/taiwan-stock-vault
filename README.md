# 台股 Obsidian 第二大腦：自動新聞更新

把 Obsidian 筆記庫放進這個 repo 後，GitHub Actions 會在台灣時間平日 07:30、18:00，以及週末 09:00 自動抓個股新聞，寫入以下位置：

- `新聞/<代號名稱> 新聞.md`：每家公司完整的新聞紀錄。保留 90 天，更早的移到 `新聞/封存/`。
- 個股筆記裡 `## 最新新聞` 區塊的標記範圍：只放最近 5 則。這部分是自動產生的，請勿手動編輯。
- `新聞/每日/YYYY-MM-DD 台股日報.md`：每天一份，開盤日由 Claude 分三次寫：08:30 盤前觀察、10:30 盤中版、13:45 收盤版；檔案最後的「附錄：新聞標題總覽」由排程自動更新。
- `新聞/每週/YYYY-MM-DD 台股週報.md`：每週六 06:00 的一週回顧與各指數週漲跌幅。說明見 `系統/規範/日報撰寫說明.md`，盤前觀察標的在 `系統/資料/盤前觀察清單.md`。

新聞來源有：證交所和櫃買中心的重大訊息、鉅亨網、Google 新聞。Google 新聞只抓關注清單裡的個股，清單在 `新聞/關注清單.md`，預設是你原本調研過的 58 檔台股。

只處理 `個股/台股` 裡已有筆記的公司：沒有筆記的公司不會建立新聞檔，也不會出現在每日總覽。公司改名但筆記檔名沒改時，在筆記 frontmatter 加 `aliases: [新名稱]`，新聞和財務數字就會照常寫入。

2026-10-20 清理時刪掉的公司列在 `系統/資料/待撰寫追蹤.txt`。它們出現新聞時會記到 `系統/資料/待撰寫佇列.md`，由每日撰寫排程補寫調研報告，說明見 `系統/規範/待撰寫排程說明.md`。

手動試跑：到 Actions → 更新個股新聞 → Run workflow，可以填入代號，只跑其中幾檔。

## 異常訊號篩選

同一個排程跑完新聞與財務數字後，會把當天的資料篩成少數值得追的候選：

- `新聞/訊號/YYYY-MM-DD 異常訊號.md`：專業訊號報告。開頭是導覽圖與重點摘要，接著是 Top 20 候選與明細（每個訊號都標可信度與來源檢核）、題材雷達、產業共振、資料檢核，文末附全部資料來源連結。
- `新聞/訊號/題材雷達.md`：近 14 天各題材每天出現的公司數。

訊號包括月營收轉折、季報毛利率與 EPS 轉折、重大訊息分級、媒體關鍵字、新聞量暴增與題材熱度。門檻與關鍵字在 `系統/資料/訊號規則.json`，可以直接改。架構與評分方式見 `系統/規範/篩選架構說明.md`。

## 財務數字

同一個排程也會更新個股筆記 frontmatter 的官方財務數字（資料來源：證交所、櫃買中心 OpenAPI）。只有數字有變時才會改檔，內文不會被動到。

| 欄位 | 說明 |
|---|---|
| 月營收年月、月營收 | 最新公布月份與當月營收（億元） |
| 月營收年增率、月營收月增率、累計營收年增率 | % |
| 財報季度 | 最新一季財報，例如 2026Q2 |
| 毛利率、營業利益率、淨利率 | 該年度累計至最新一季（%） |
| 累計EPS | 該年度累計至最新一季（元） |
| 現金股利、股利所屬年度 | 最近一個盈餘年度的每股現金股利合計（季配息會加總）。目前只有上市公司：櫃買中心的股利資料停在 2021 年 |
| 財務更新 | 最後一次數字有變動的日期 |
