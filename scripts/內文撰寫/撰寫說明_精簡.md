# 個股筆記內文撰寫（精簡版）：工作說明

你負責替台灣上市櫃中小型公司撰寫 Obsidian 個股筆記的精簡內文（繁體中文）。不要呼叫任何 mcp__hearthbot__ 工具。

## 每家公司要做的事
1. 每家只做 1 次 WebSearch（mode standard），例如「<代號> <名稱> 主要產品 營收 EPS 2026」，從結果標題與摘要取得主要產品、營收比重、最近一年或一季的營收與 EPS。真的必要時才補 1 次 WebFetch。證交所、公開資訊觀測站、鉅亨網、Google 新聞在這個環境連不到，不要嘗試。
2. 依下方格式寫內容檔，存到本機 `SCRATCH/content/<代號>.md`。
3. 每寫完 3 至 5 家，用 mcp__remote-devices__device_bash（必要時先用 ToolSearch "select:mcp__remote-devices__device_bash" 載入）一次寫到裝置：每家一個 quoted heredoc，`cat > $HOME/twfill/content/<代號>.md <<'MDEOF'` …內容… `MDEOF`，最後在同一個指令裡 `md5sum` 這幾個檔。
4. 本機也 `md5sum`，兩邊必須相同；不同就重寫裝置上的那一檔。
5. 不要動 Obsidian 筆記本身，也不要執行 fill_notes.py。

## 內容檔格式（嚴格遵守）
```
@@code 1101
@@fm 供應鏈位置: 上游（水泥與建材）
@@ch1
> [!info] 撰寫說明
> 精簡版，由 Claude 依公開資料整理，資料截至 2026-10-07。來源：<實際用到的來源名稱>。#待校對

- **核心業務：** …
- **營收結構：** …
- **營運據點：** …
- **長期方向：** …
@@ch2
- **競爭優勢：** …
- **主要對手：** …
- **觀察重點：** …
@@ch3
資料日期：2026-10-07，最新月營收與三率請見[[#相關連結]]的公開資訊觀測站。#待校對

- **營收規模：** …
- **獲利：** …（EPS、毛利率等，有查到才寫，寫明期間）
- **財務特色：** …
@@ch4
- **產業週期：** …
- **營運風險：** …
- **其他風險：** …（地緣政治、法規、匯率、原物料等，挑相關的）
@@chain
- 上游：…
- 下游／客戶：…
- 同業：…
```
`@@fm` 只放「供應鏈位置」。

## 寫作要求
- 每章 3 至 5 點，每點 1 至 2 句完整句子，每家約 800 至 1,500 字。
- 數字必須來自這次查到的來源，查不到就寫定性描述，不要編造。不確定的寫「推估」。公司資訊極少時寫短一點，並在撰寫說明加一句「公開資料有限」。
- 台股公司連結用 `[[代號名稱]]`（例如 [[2330台積電]]，名稱用證交所簡稱）；外國公司只用這些已存在的：AAPL蘋果 AMAT應用材料 AMD超微 AMKR艾克爾 AMZN亞馬遜 ARM安謀 ASML艾司摩爾 AVGO博通 CDNS益華電腦 CSCO思科 GOOGL谷歌 INTC英特爾 KLAC科磊 LRCX科林研發 META臉書 MRVL邁威爾 MSFT微軟 NVDA輝達 QCOM高通 SNPS新思科技 SONY索尼 005930三星電子，其他直接寫名字。名詞可連 [[毛利率]] [[營業利益率]] [[ROE]] [[CapEx]]。
- 白話、不誇大、不用 emoji。

## 回報
完成後只回報一行一家：`<代號>: OK md5=<前8碼>` 或 `<代號>: 問題說明`。不要貼內文。
