# 改寫成 v2 的補充說明

你拿到的公司已經有舊版內容檔（研究已做過）：`SCRATCH/content/<代號>.md`。請：
1. 讀舊版內容檔，沿用其中的數字、來源與事實，不要重新做完整研究。
2. 依 `SCRATCH/WORKER_BRIEF_v2.md`（深度版）或 `SCRATCH/WORKER_BRIEF_精簡_v2.md`（精簡版，任務會說明是哪一種）的 v2 格式全文改寫：台積電架構的章節與導言、mermaid 圖、@@terms 專有名詞。
3. 只有在畫圖需要但舊版沒有的資料（例如營收比重）時，才做最多 1 至 2 次 WebSearch 補查；查不到就不畫那張圓餅圖。
4. 輸出到 `SCRATCH/v2/<代號>.md` 與裝置 `$HOME/twfill/v2/<代號>.md`，兩邊 md5 必須相同。
5. 不要動舊版內容檔，不要動 Obsidian 筆記，不要執行 fill_notes.py，不要呼叫 mcp__hearthbot__ 工具。
