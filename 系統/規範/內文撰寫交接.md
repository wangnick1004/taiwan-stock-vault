## Pipeline
1. Workers (general-purpose Agents, about 5 in parallel to save usage) write one content file per company to `$SCRATCH/v2/<code>.md`. Their prompt is: "Read `$SCRATCH/BRIEF_C.md` in full and follow it," plus that line's 12 companies and an industry hint.
   - BRIEF_C.md points to `LOCAL_MODE.md`, `v2_範例_2303.md` and `系統/規範/撰寫說明_精簡.md` (with its v3 section). Before using it, change SCRATCH in BRIEF_C.md to your own directory.
   - Content file format: `@@code`, `@@fm 供應鏈位置:`, `@@fm 成立:`, `@@ch1`–`@@ch4`, `@@terms` (one `分類|名詞|說明` per line), `@@chain`.
   - A v3 file contains 「2026-10-08」 and includes the 5-year table and ROIC/WACC. Finance stocks use ROE versus the CAPM cost of equity instead.
2. Run `SCRATCH=... bash sync.sh`:
   - It merges origin/main.
   - It runs `fixlinks.py`, which fixes `[[code+name]]` links that point to no existing note. It also strips `@@chain` from 2330 and 2454.
   - It runs `系統/scripts/fill_notes.py . $SCRATCH/v2 --replace`.
   - It commits 個股 and 名詞, pushes the branch `claude/project-thread-hqxpyj`, then pushes **HEAD:main**. The user approved writing straight to main on 2026-10-07.
   - sync.sh hard-codes the repo path /home/claude/taiwan-stock-vault and branch claude/project-thread-hqxpyj. Change both to your session's values.
3. fill_notes rules:
   - It fills only empty sections. With `--replace`, it overwrites only notes whose frontmatter has `內文更新`, meaning notes Claude wrote.
   - It never touches the news:start/end markers.
   - It skips iCloud copies named 「名稱 2.md」.
