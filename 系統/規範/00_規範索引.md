# 規範索引（Claude 每次動工前先讀這份）

這個資料夾集中所有給 Claude 反覆閱讀的撰寫規範與工作流程說明。使用者日常只用 `個股/`、`新聞/`、`名詞/`、`統計/`；`系統/` 底下是規範、程式與資料，使用者不需要打開。

## 資料夾結構（2026-10-23 整併）

| 位置 | 內容 |
|---|---|
| `個股/台股/`、`個股/海外/` | 個股筆記（檔名＝代號名稱，**永遠不改檔名**） |
| `個股/產業索引/`、`個股/產業鏈/`、`個股/台股總索引.md` | 產業分類索引、供應鏈 MOC |
| `新聞/` | `<代號名稱> 新聞.md`、`每日/`（日報與標題總覽）、`每週/`（週報）、`訊號/`（異常訊號）、`關注清單.md` |
| `名詞/` | 專有名詞：半導體、應用、金融、產業 |
| `統計/` | WACC與ROIC彙整、`0050總覽文/` |
| `系統/規範/` | 本資料夾：所有規範 |
| `系統/scripts/` | 自動化程式（GitHub Actions 與排程呼叫） |
| `系統/資料/` | 程式用的資料：財務摘要、公司資料、0050 名單、訊號規則、待撰寫佇列；`內文撰寫/` 是撰寫佇列與旗標 |
| `系統/tests/` | 測試：`python3 系統/tests/test_financials.py`、`python3 系統/tests/test_screen.py` |

## 共通規則

- 不改檔名；新聞檔名必須和個股筆記檔名完全一致（股票名稱的「*」拿掉）。
- 個股筆記的 `## 最新新聞` 只由自動化改寫 `<!-- news:start -->` 與 `<!-- news:end -->` 之間的文字。
- 未查證內容標 #待校對。
- 內文以 10 年內仍有效的知識為主，要有完整敘述與統計數據（ROIC、WACC 等）。
- 2026-10-20 起，研究內文的修訂只針對 0050 成分股，定期進行。
- 使用者慣例：直接推 main。
